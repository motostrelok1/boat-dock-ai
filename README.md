# Лодка + ИИ — Вход в док

**Статус: 🚧 В работе**

Проект по обучению нейросети управлять лодкой для входа в док. Лодка движется с постоянной скоростью, нейросеть управляет только рулём (поворот влево/вправо).

---

## Что реализовано

### 🧠 Нейросеть
- Архитектура: feedforward, 4 входа → 8 скрытых → 1 выход
- Входы: расстояние до цели, угловая ошибка, sin/cos курса
- Выход: команда руля (-1…1)
- Обучение: эволюционный алгоритм (популяция 50 особей)

### 🎮 Симуляция
- Лодка стартует слева со случайным курсом (0–360°)
- **Остров** справа с прорезью-воротами
- **Точка входа** — на 30 пикселей левее острова, куда целится ИИ
- **Створ дока** — пунктирные линии от точки входа вглубь острова
- При неудаче — автоперезапуск через 0.8с с новым лейаутом

### 🖥️ Интерфейс
- Canvas 2D отрисовка: лодка, остров, след, предиктивный вектор (+3с)
- HUD: скорость, курс, угол руля, дистанция, угол до цели
- Прогресс-бар при обучении (поколение / особь / скор)

### 🎓 Обучение
- **Непрерывное обучение** — кнопка запускает бесконечный цикл
- Каждые 10 поколений лучшая сеть автоматически загружается в лодку
- Кнопка «Стоп» — прерывает обучение, загружает лучшую модель
- Сохранение/загрузка в `localStorage`
- Экспорт/импорт в JSON

### 🏆 Reward function
- Бонус за продвижение вправо
- Штраф за расстояние до точки входа
- Бонус за выровненность с воротами
- Бонус за близость к центру ворот по Y
- Штраф за время и резкие повороты

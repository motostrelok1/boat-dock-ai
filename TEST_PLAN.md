# Тестирование Boat Dock AI

## Автоматически
Запуск: `npm ci && npm test && npm run build`. GitHub Actions выполняет эти команды на PR.

Проверяются: сохранение модели, ручное управление, старт перед линией дока, границы острова,
пролёт через waypoint за один шаг, элитизм, повторяемость benchmark.

## Визуальный тест
После `npm run dev` открыть `http://localhost:5173/benchmark.html`
(или адрес/порт Vite, напечатанный в терминале).

1. Нажать «Проверить 20 сценариев» для текущей или сохранённой модели.
2. Посмотреть процент успешных заходов и средний score.
3. Нажимать номера испытаний — на карте будет показана траектория и граница входа.
4. Импортировать файл `brains/boat-dock-brain-gen2000.json` и повторить.
5. Для корректного сравнения использовать одинаковые 20 фиксированных сценариев.

Проценты показывают результат исключительно на этих 20 картах **без** waypoints
и запретных зон. Это диагностический тест, а не гарантия качества на новых картах.
Для Stage 2.2 понадобятся отдельные тесты обхода зон, оценка на невиденных seed
и сопоставление successRate с collisionRate.

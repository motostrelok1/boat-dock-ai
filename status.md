## Stage 2.1 — Обязательные точки маршрута и точки обхода (завершено)

### 2.1.1 Зелёные обязательные точки (waypoints)
- [x] Кнопка «Маршрут» + дропдаун количества: 1 / 2 / 3 / 4 / 5
- [x] Радиус точки: 3 px, зелёный цвет, порядковая цифра внутри
- [x] ЛКМ по полю — установка точки; повторный клик / режим — убрать; можно плавать без точек
- [x] Логика движения: старт → точка 1 → точка 2 → … → точка N → точка входа в фарватер
- [x] Доворот к следующей точке только после физического прохождения текущей (попадание в радиус 3px)
- [x] Вознаграждение за проход каждой обязательной точки (+1000)
- [x] **Чекбокс «расставить случайно»** — при включении точки генерируются автоматически при каждом сбросе/авторестарте

### 2.1.2 Красные точки обхода (avoid zones)
- [x] Отдельная кнопка «Запреты» + дропдаун радиуса: 10 / 20 / 30 px, красный цвет
- [x] Отдельный дропдаун количества: **1–15**
- [x] ЛКМ по полю — установка точки обхода
- [x] Обязательный обход на пути от одной зелёной точки к следующей или к точке входа в фарватер
- [x] Попадание в красную зону = незачёт, финиш, −1000 к скору

### 2.1.3 Расширение архитектуры сети
- [x] Сеть **6→8→1**: dist, angle, sin(h), cos(h), avoid_dist, avoid_angle
- [x] Миграция старых мозгов (4→6 входов) при загрузке — новые веса инициализируются нулями
- [x] Сеть видит ближайшую avoid-зону и учится маневрировать

### 2.1.4 Прочие изменения stage 2.1
- [x] **Время жизни увеличено до 200 сек** (было 100) — больше времени на сложные маршруты с waypoints и avoid-зонами
- [x] **Avoid-зоны как входы сети** — нейросеть получает avoid_dist и avoid_angle в реальном времени
- [x] **Canvas-debug сети** расширен до 6 входов + руль

## Известные ограничения / TODO

- Обучение с нуля на случайном спавне требует больше поколений, чем на фиксированном старте
- Сеть 6→8→1 требует дообучения — старый мозг сохраняет базовое поведение, но avoid-входы обучаются с нуля
- Нет визуализации лучшей траектории (только текущий след)
- Нет сравнения нескольких сетей одновременно

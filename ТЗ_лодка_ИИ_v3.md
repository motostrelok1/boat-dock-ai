## 1. Общее описание

Веб-симуляция, в которой кастомная feedforward нейросеть (эволюционное обучение) учится управлять лодкой. Лодка движется с постоянной скоростью, ИИ управляет только рулём (поворот влево/вправо). Цель — правильно войти в точку входа фарватера и пройти его до конца.

Ключевое условие: если лодка пересекает точку входа, но не попадает в коридор ворот с правильным курсом — эпизод немедленно завершается с незачётом.

## 4. Модуль `boat.js`

```js
export class Boat {
  constructor(x, y)
}
```

### Поля
| Поле | Значение | Описание |
|------|----------|----------|
| `x`, `y` | 0, 0 | Позиция (центр лодки) |
| `heading` | 0 | Курс в радианах (0 = вправо) |
| `speed` | **30** | Постоянная скорость, пикс/с |
| `maxTurnRate` | 1.2 | Макс скорость поворота, рад/с |
| `rudderAngle` | 0 | Команда руля, clamp(-1..1) |
| `length` | 30 | Длина лодки |
| `width` | 12 | Ширина лодки |
| `trail` | [] | Массив точек `{x, y}` — след |
| `maxTrailLength` | 200 | Макс длина следа |

> **Примечание по физике:** минимальный радиус разворота лодки на полном руле = `speed / maxTurnRate` = `30 / 1.2` = **25 px**. `gateWidth = boat.width * 3.5` оставлен без изменений (42 px), что при текущей скорости даёт запас манёвренности.

### Методы

**`update(dt, rudderCmd)`**
1. `this.rudderAngle = clamp(rudderCmd, -1, 1)`
2. `this.heading += this.rudderAngle * this.maxTurnRate * dt`
3. `this.heading = this.heading % (Math.PI * 2)`
4. `this.x += Math.cos(this.heading) * this.speed * dt`
5. `this.y += Math.sin(this.heading) * this.speed * dt`
6. Добавить `{x, y}` в `trail`, если длина > 200 — удалить первый элемент

**`getPrediction(seconds)`**
- Возвращает `{x, y}` — позиция через `seconds` секунд при текущем курсе и скорости (без поворотов)

**`getState()`**
- Возвращает объект с `x, y, heading, speed, rudderAngle`

**`reset(x, y)`**
- Сбрасывает `x, y`, `heading = 0`, `rudderAngle = 0`, `trail = []`

## 5. Модуль `neuralNetwork.js`

```js
export class NeuralNetwork {
  constructor(inputSize, hiddenSize = 8, outputSize = 1)
}
```

### Архитектура
- **Входной слой:** **6** нейронов (dist, angle, sin(h), cos(h), avoid_dist, avoid_angle)
- **Скрытый слой:** 8 нейронов, активация `tanh`
- **Выходной слой:** 1 нейрон, активация `tanh` (значение -1..1 = руль)

### Инициализация весов
- Xavier: `scale = sqrt(2 / inputSize)` для weightsIH, `sqrt(2 / hiddenSize)` для weightsHO
- Смещения (biases): случайные в диапазоне `(-0.25, 0.25)`

### Методы

**`forward(inputs)`**
- Скрытый слой: `sum = biasH[i] + Σ(weightsIH[i][j] * inputs[j])`, `tanh(sum)`
- Выходной слой: `sum = biasO[i] + Σ(weightsHO[i][j] * hidden[j])`, `tanh(sum)`
- Возвращает массив outputs

**`mutate(rate = 0.1, strength = 0.3)`**
- Создаёт глубокую копию сети
- Для каждого веса/смещения: с вероятностью `rate` добавить `(Math.random() - 0.5) * strength`
- Возвращает мутированную копию

**`static crossover(a, b)`**
- Для каждого веса/смещения: 50/50 — взять от `a` или `b`

**`toJSON() / static fromJSON(data)`**
- Сериализация/десериализация всех весов и гиперпараметров

**`migrateInputSize(newInputSize)`** ⭐ новое (Stage 2.1)
- Если текущий `inputSize` уже равен `newInputSize` — ничего не делать
- Создаёт новую матрицу `weightsIH` размером `[hiddenSize][newInputSize]`
- Копирует старые веса для существующих входов, новые инициализирует нулями
- Обновляет `this.inputSize = newInputSize`

*(без изменений от v2)*


**`getInputs()`**

2. `angleDiff / π` — угловая ошибка до текущей цели
3. `sin(this.boat.heading)`
4. `cos(this.boat.heading)`
5. `avoid_dist / diag` — расстояние до ближайшей красной зоны (0 если зон нет)

**`getInputs()`**
Возвращает массив из 4 значений, вычисленных относительно `getNavTarget()`:
1. `dist / diag` — расстояние до текущей цели, нормированное на диагональ канваса: `diag = Math.sqrt(width**2 + height**2)`
2. `angleDiff / π` — угловая ошибка до текущей цели навигации
3. `sin(this.boat.heading)`
4. `cos(this.boat.heading)`

**`normalizeAngle(angle)`**
- Приводит угол к диапазону `[-π, π]`

**`update(dt)`**
Последовательность проверок (**строго в этом порядке**):
1. Если `!running || finished` — выход
2. `time += dt`
3. Если `time >= maxTime` → `finished = true`, `score = calculateScore() - 500` → выход
4. Если вылет за экран (±50px) → `finished = true`, `score = calculateScore() - 2000` → выход
5. **`checkAvoidZones()`** — попадание в красную зону → `finished = true`, `score = calculateScore() - 1000` → выход
6. **`checkWaypoints()`** — прохождение обязательной точки → награда +1000, переход к следующей
7. **`checkEntryPoint()`** — проверка пересечения точки входа
   - Если внутри неё выставлен `finished = true` (незачёт) — выход
8. **`checkIslandCollision()`** — столкновение с берегом острова
   - `finished = true`, `score = calculateScore() - 5000` → выход
9. **`checkDockEntry()`** — полное прохождение фарватера
   - `finished = true`, `score = calculateScore() + 10000 + (maxTime - time) * 100` → выход
10. Если `aiEnabled`: получить `inputs` → `nn.forward(inputs)` → передать руль в `boat.update(dt, rudder)`
11. **Dense Reward** (см. отдельный раздел ниже)

**`checkWaypoints()`** ⭐ новое (Stage 2.1)
- Если `currentWaypointIndex >= waypoints.length` — выход (все пройдены)
- Берётся `wp = waypoints[currentWaypointIndex]`
- Если `!wp.passed` и расстояние от лодки до `wp` ≤ 3 пикселей:
  - `wp.passed = true`
  - `score += 1000`
  - `currentWaypointIndex++`
  - `prevDist = null` (сброс для dense reward — новая цель)

**`checkAvoidZones()`** ⭐ новое (Stage 2.1)
- Для каждой `zone` в `avoidZones`:
  - Если расстояние от лодки до центра `zone` ≤ `zone.radius`:
    - `finished = true`
    - `score = calculateScore() - 1000`
    - Возвращает `true` (столкновение)
- Возвращает `false`

**`checkIslandCollision()`**
Последовательность проверок (**строго в этом порядке**):
1. Если `!running || finished` — выход
2. `time += dt`
3. Если `time >= maxTime` → `finished = true`, `score = calculateScore() - 500` → выход
4. Если вылет за экран (±50px) → `finished = true`, `score = calculateScore() - 2000` → выход
5. **`checkEntryPoint()`** — проверка пересечения точки входа
   - Если внутри неё выставлен `finished = true` (незачёт) — выход
6. **`checkIslandCollision()`** — столкновение с берегом острова
   - `finished = true`, `score = calculateScore() - 5000` → выход
7. **`checkDockEntry()`** — полное прохождение фарватера
   - `finished = true`, `score = calculateScore() + 10000 + (maxTime - time) * 100` → выход
8. Если `aiEnabled`: получить `inputs` → `nn.forward(inputs)` → передать руль в `boat.update(dt, rudder)`
9. **Dense Reward** (см. отдельный раздел ниже)

**`checkIslandCollision()`**
- Лодка внутри острова по X: `boat.x > islandX && boat.x < islandX + islandW`
- При этом вне коридора ворот по Y: `boat.y < gateY - gateWidth/2 || boat.y > gateY + gateWidth/2` → столкновение

**`checkEntryPoint()`**
- Если `entryChecked` уже true или `boat.x <= entryX` — выход
- Установить `entryChecked = true`
- Проверить два условия:
  - `inGateY = Math.abs(boat.y - gateY) < gateWidth / 2`
  - `alignedHeading = Math.abs(normalizeAngle(boat.heading)) < 0.3` — курс в пределах ±17°
- Если **оба** true → `entrySuccess = true`, `prevDist = null`
- Если хотя бы одно false → `entrySuccess = false`, `finished = true`, `score = calculateScore() - 3000`

**`checkDockEntry()`**
- `passedDock = boat.x > islandX + islandW`
- `alignedY = Math.abs(boat.y - gateY) < gateWidth / 2`
- Возвращает `passedDock && alignedY && entrySuccess`

**`isOverIsland(x, y)`** ⭐ новое
- Проверяет, находится ли точка внутри верхней или нижней части острова (всё, кроме ворот):
  - Если `x` внутри `[islandX, islandX + islandW]`:
    - Проверяет Y в верхней части: `[islandY, gateY - gateWidth/2]`
    - Проверяет Y в нижней части: `[gateY + gateWidth/2, islandY + islandH]`
  - Возвращает `true` если точка внутри любой из частей

**`calculateScore()`**
```
score = this.score  (уже накопленная dense reward)
score -= dist * 0.3
score -= angleDiff * 10
score -= yOffset * 0.2
return score
```
> Используется только для финального начисления при `finished = true`. Dense reward накапливается напрямую в `this.score` внутри `update()`.

**`reset(network = null, randomize = true)`**
- Если `randomize` — вызвать `randomizeLayout()`
- `time = 0`, `finished = false`, `running = true`, `score = 0`
- `entryChecked = false`, `entrySuccess = false`
- `prevDist = null`, `prevEntryDist = null`
- `currentWaypointIndex = 0`, `waypointsPassed = 0`
- Если `waypoints` заданы — сбросить `passed = false` у всех
- Если `network` передан — `this.nn = network`

**`resetBrain()`**
- `localStorage.removeItem('boat-dock-ai-best')`
- `this.nn = new NeuralNetwork(6, 8, 1)`
- `bestNetwork = null`, `bestScore = -Infinity`, `generation = 1`, `population = []`
- `this.waypoints = []`, `this.avoidZones = []`
- `this.reset(null, true)`

**`saveBestBrain()` / `loadBestBrain()` / `exportBrain()` / `importBrain()`**
- Сохранение/загрузка в `localStorage` (ключ `boat-dock-ai-best`)
- Экспорт/импорт JSON-файла
- При загрузке старых мозгов (4 входа) — вызвать `nn.migrateInputSize(6)`

## 7. Функция награды (dense reward в `update()`)

| Компонент | Формула | Вес/коэффициент | Назначение |
|-----------|---------|-----------------|------------|
| Глобальное притяжение к входу | `(prevEntryDist - entryDist) * 1.0` | 1.0 | Сеть всегда тянется к `entryX` независимо от фазы |
| Угол к текущей цели | `speed * cos(angleDiff) * dt * 20` | **20** | Нос обязан смотреть на цель — **главный приоритет** |
| Дистанция к текущей цели | `(prevDist - currDist) * 1` | **1** | Приближение к цели — вторично |
| Бонус «вглубь» | `speed * cos(heading) * dt * deepBonus` | 2 (до входа), **8** (после) | Стимул держать курс вправо, особенно в фарватере |
| Штраф за руль | `-\|rudder\| * dt * 2` | 2 | Штраф за излишние повороты |
| **Бонус за waypoint** | `+1000` (единоразово) | — | За прохождение каждой обязательной зелёной точки |
| **Штраф за avoid-зону** | `-1000` (единоразово) | — | За попадание в красную запретную зону |

> **Ключевой принцип:** угол к цели (20) >> дистанция (1). Лодка должна разворачиваться лицом к цели, даже если это временно увеличивает дистанцию.

## 13. Критические поведенческие требования

1. **Поле** 1800×1000 пикселей.
2. **Скорость лодки** постоянна — **30 пикс/с**.
3. **Время жизни эпизода** — **200 секунд**.
4. **Стартовая позиция** — случайная точка на всём экране, с защитой от спавна внутри острова (`isOverIsland`).
5. **Точка входа** (`entryX`) расположена строго на **60 пикселей левее** левого края острова.
6. **Обязательные точки (waypoints)** — зелёные круги радиуса 3px, расставляются вручную ЛКМ или автоматически (чекбокс «расставить случайно»). Лодка обязана пройти их **по порядку** (1 → 2 → … → N). Доворот к следующей точке — только после прохождения текущей. Награда +1000 за каждую.
7. **Запретные зоны (avoid)** — красные круги радиуса 10/20/30px, расставляются вручную ЛКМ. Попадание лодки в зону = **незачёт**, эпизод завершается, штраф −1000.
8. При пересечении `entryX` по X проверяется **строгое условие входа**:
   - Лодка внутри коридора по Y (±gateWidth/2 от gateY)
   - Курс выровнен с фарватером (±0.3 рад ≈ ±17°)
9. Если условие входа не выполнено — эпизод **немедленно** завершается (`finished = true`), выводится статус «НЕЗАЧЁТ».
10. После успешного входа лодка должна пройти фарватер до `x > islandX + islandW`.
11. Вылет из коридора **внутри острова** после успешного входа = столкновение с берегом.
12. Цель навигации, относительно которой считаются входы сети (`dist`, `angleDiff`), **меняется по ходу эпизода**:
    - Сначала — ближайшая непройденная waypoint (если есть)
    - Затем — точка входа `(entryX, gateY)`
    - После успешного входа — точка за выходом из дока `(islandX+islandW+60, gateY)`
13. **Dense reward** приоритизирует угол (вес 20) над дистанцией (вес 1) — лодка обязана разворачиваться лицом к цели.
14. Глобальное притяжение к `entryX` действует **всегда**, независимо от фазы эпизода.
15. **Сеть получает 6 входов**: `dist`, `angle`, `sin(h)`, `cos(h)`, `avoid_dist`, `avoid_angle`. Если запретных зон нет — avoid-входы = 0.
16. Старые сохранённые мозги (4 входа) при загрузке **автоматически мигрируют** до 6 входов через `migrateInputSize(6)`.

5. **Точка входа** (`entryX`) расположена строго на **60 пикселей левее** левого края острова.
6. При пересечении `entryX` по X проверяется **строгое условие входа**:
   - Лодка внутри коридора по Y (±gateWidth/2 от gateY)
   - Курс выровнен с фарватером (±0.3 рад ≈ ±17°)
7. Если условие входа не выполнено — эпизод **немедленно** завершается (`finished = true`), выводится статус «НЕЗАЧЁТ».
8. После успешного входа лодка должна пройти фарватер до `x > islandX + islandW`.
9. Вылет из коридора **внутри острова** после успешного входа = столкновение с берегом.
10. Цель навигации, относительно которой считаются входы сети (`dist`, `angleDiff`), **меняется по ходу эпизода**: до входа — точка входа `(entryX, gateY)`, после успешного входа — точка за выходом из дока `(islandX+islandW+60, gateY)`.
11. **Dense reward** приоритизирует угол (вес 20) над дистанцией (вес 1) — лодка обязана разворачиваться лицом к цели.
12. Глобальное притяжение к `entryX` действует **всегда**, независимо от фазы эпизода.
